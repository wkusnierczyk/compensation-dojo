\section{Purpose \& Positioning}

Compensation Dojo is a negotiation training simulator focused on realistic compensation discussions under time pressure. It emphasizes experiential learning and candid feedback rather than live coaching.

Failure is expected and treated as a valuable learning outcome.

\section{Core Assumptions}

\begin{itemize}
\item Negotiation skill is learned through experience
\item Real negotiations are time-bounded and imperfect
\item Strict realism improves learning outcomes
\item Feedback is most effective after completion
\end{itemize}

\section{Session Flow}

Each session follows a fixed structure:
\begin{enumerate}
\item Setup Phase
\item Negotiation Start
\item Timed Negotiation
\item Termination
\item Expectation Reveal
\item Closure \& Feedback
\end{enumerate}

\section{Setup Phase}

Users configure:
\begin{itemize}
\item Role (Candidate or Hiring Manager)
\item Learning goals
\item Opponent style
\item Time limit
\item Negotiation context
\end{itemize}

An explicit warning is given before negotiation begins.

\section{Negotiation Phase}

Once started:
\begin{itemize}
\item The system is fully in-character
\item All messages are treated as negotiation moves
\item Time remaining is displayed each turn
\item Unrealistic behavior is logged silently
\end{itemize}

\section{Termination}

Negotiation ends immediately when time expires or an agreement is reached.

\section{Expectation Reveal}

Candidates disclose their original compensation target.

\section{Closure \& Feedback}

The system provides:
\begin{itemize}
\item Outcome summary
\item Expectation calibration
\item Candid, actionable skill feedback
\end{itemize}

\section{Constraints}

\begin{itemize}
\item No coaching during negotiation
\item No breaking character
\item Strict time enforcement
\end{itemize}

\section{Intended Use}

Compensation Dojo is designed for realistic negotiation practice, strategy testing, and skill development under pressure.
